## 证据

完整测试在临时目录生成模拟 WB，与独立 NumPy、Pillow、SciPy 和实际工作簿读取对照。公开 CI 不再排除静态示例依赖的测试。未修改的 ImageJ 1.54g：72 组滚球配置、28,152 个像素一致，81 种椭圆面积一致。

真实系统 WebKit 检查裁剪、翻转、显示增强、透明度、旋转、PNG、TIFF、PPTX 和 256 级灰度。实际 DOM、事件与图像解码检查涵盖设计、条件、方法、分母复制、防重复、恢复、统计映射、五种导出和项目重开。结果见 verification/webkit-results.json。跨平台构建以 GitHub Actions 实际结果为准。
